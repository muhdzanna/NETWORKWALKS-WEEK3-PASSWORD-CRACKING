
# PM1 – Password Cracking with John the Ripper

## Objective
To recover the password of a protected PDF using John the Ripper (JTR) and Johnny GUI.

## Tools Used
- John the Ripper
- Johnny GUI
- PDF Hash Extractor

## Practical Activities
1. Installed John the Ripper and Johnny.
2. Configured Johnny with the John executable.
3. Extracted the PDF password hash.
4. Saved the hash as hash1.txt.
5. Loaded the hash into Johnny.
6. Started the password recovery process.
7. Successfully recovered the PDF password.

## Learning Outcomes
- Understanding PDF password hashes.
- Using John the Ripper for password recovery.
- Configuring Johnny GUI.
- Troubleshooting missing rule-file errors.
