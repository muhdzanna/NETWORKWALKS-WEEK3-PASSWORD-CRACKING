
# PM2 – Password Cracking

## Objective
To recover the password of a protected PDF using the password-cracking tools provided in the NetworkWalks lab.

## Tools Used
- Hash Calculator
- Password Cracker

## Practical Activities
1. Uploaded the protected PDF to the hash calculator.
2. Extracted the PDF hash.
3. Used the Password Cracker tool.
4. Successfully recovered the PDF password.
5. Opened the protected PDF.
6. Captured the completion flag.

## Learning Outcomes
- Understanding password hashes.
- Learning the password recovery process.
- Understanding password protection.
- Practising cybersecurity tools in a controlled lab.

## Evidence
Screenshots of the hash extraction, password recovery and successful PDF opening are stored in the evidence folder.

## Result
Successfully completed PM2.
