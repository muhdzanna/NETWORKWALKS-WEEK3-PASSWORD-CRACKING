
# NETWORKWALKS WEEK 3 – PASSWORD CRACKING

## Cybersecurity Internship | Week 3

This repository documents my practical work and learning outcomes from Week 3 of the NetworkWalks Cybersecurity Internship.

The focus of this week's activities was password cracking, password recovery and understanding password security.

## Project Modules

### PM1 – Password Cracking with John the Ripper (JTR)

**Tools used:**
- John the Ripper
- Johnny GUI
- PDF Hash Extractor

**Activities:**
- Installed and configured John the Ripper and Johnny.
- Extracted a password hash from a protected PDF.
- Loaded the hash file into Johnny.
- Troubleshot tool configuration issues.
- Successfully recovered the PDF password.

### PM2 – Password Cracking with NetworkWalks Tools

**Tools used:**
- Hash Calculator
- Password Cracker

**Activities:**
- Extracted the PDF hash.
- Used the password-cracking tool.
- Successfully recovered the password.
- Opened the protected PDF.
- Captured the completion flag.
